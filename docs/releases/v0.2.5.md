## 0.2.5

Real wizard substeps and start screens. / Реальные подшаги мастера и экраны старта.

### New / Новое

- The Incus and container steps now report real substeps (`apt-update`, `install-packages`, `admin-init`; `storage-pool`, `bridge`, `profile`, `launch-image`, `wait-dns`) as running, done, failed or skipped (reruns stay idempotent), with `startedAt`/`endedAt`. / Шаги Incus и контейнера показывают реальные подшаги (`apt-update`, `install-packages`, `admin-init`; `storage-pool`, `bridge`, `profile`, `launch-image`, `wait-dns`) — running, done, failed или skipped (повторный запуск идемпотентен), с `startedAt`/`endedAt`.
- The start screen has Studio screens for start, install, Incus and ready, a success token, a light shell skin, and a short pause before the ready screen. / На старте — экраны Studio: start, install, Incus и ready, success-токен, светлый скин оболочки и короткая пауза перед экраном ready.

### Security / Безопасность

- The live wizard log keeps the last 200 lines and redacts the root password and the host token from the log, problems and details (tested). / Живой лог мастера хранит последние 200 строк и скрывает пароль root и токен хоста в логе, проблемах и подробностях (есть тесты).

To update the server: `sudo vibechat-server update`. Check every asset against this release's `SHA256SUMS` (the server's self-update does the same for the `.deb` before `dpkg -i`).
Обновление сервера: `sudo vibechat-server update`. Сверьте файлы с `SHA256SUMS` этого релиза (самообновление сервера так же проверяет `.deb` перед `dpkg -i`).
