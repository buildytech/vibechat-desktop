## 0.2.11

Settings with sections, light and dark themes, skins; File → Settings works again; an empty project opens the Editor. / Настройки с разделами, светлая и тёмная темы, скины; File → Settings снова работает; пустой проект открывает редактор.

### Added / Добавлено

- Settings is a sectioned screen with a left menu, like an IDE: General, Appearance, Models and keys, Account, Server, About. Each section has its own link (`/settings/appearance`), and a search box filters the menu. Sections come from one registry, so a new feature adds one entry and one component (Studio ADR 0007). The old one-page settings are moved into the sections. / Настройки стали экраном с разделами и меню слева, как в IDE: Общие, Оформление, Модели и ключи, Аккаунт, Сервер, О программе. У каждого раздела своя ссылка (`/settings/appearance`), поиск фильтрует меню. Разделы описаны в одном реестре: новая возможность добавляет одну запись и один компонент (ADR 0007 Studio). Старая одностраничная настройка разнесена по разделам.
- Light, dark and system themes for the whole app, including the code editor. The choice is saved on this computer and applied before the first paint, so the window does not flash. The account menu has a quick theme switch. Dark stays the default. / Светлая, тёмная и системная тема для всего приложения, включая редактор кода. Выбор сохраняется на этом компьютере и применяется до первой отрисовки, без вспышки. В меню аккаунта есть быстрый переключатель темы. По умолчанию по-прежнему тёмная.
- Built-in skins Ember (default), Graphite and Ocean under Settings → Appearance. Each skin has light and dark colour sets in the BuildY chat Brand Skin palette shape, and tests check WCAG AA contrast in both modes. / Встроенные скины Ember (по умолчанию), Graphite и Ocean в «Настройки → Оформление». У каждого скина светлый и тёмный набор цветов в формате палитры Brand Skin BuildY chat; тесты проверяют контраст WCAG AA в обоих режимах.

### Fixed / Исправлено

- File → Settings in the native menu left the window on "Connected. Opening the server's Studio…" until Quit. The menu loaded `/settings` from the app's own origin (the start screen), not from the server. Now, when connected, the app signs the window in to the server again and opens its Settings (`/auth/session?…&next=/settings`; only a path of the same origin is accepted); when not connected, it opens the start screen. If the start screen still waits for 10 seconds, it shows an error with Retry and Back. / File → Settings в нативном меню оставлял окно на «Подключено. Открывается Studio сервера…» до выхода из приложения. Меню загружало `/settings` с собственного адреса приложения (стартовый экран), а не с сервера. Теперь при подключении приложение заново входит на сервер и открывает его настройки (`/auth/session?…&next=/settings`, принимается только путь того же адреса); без подключения открывается стартовый экран. Если стартовый экран ждёт дольше 10 секунд, появляется ошибка с кнопками «Повторить» и «Назад».
- An empty project (for example, the empty template before a ZIP import) opens the Editor with a hint and an Import ZIP link instead of the preview's "This project has no files yet…". / Пустой проект (например, пустой шаблон до импорта ZIP) открывает редактор с подсказкой и ссылкой «Импорт ZIP» вместо текста превью «This project has no files yet…».

### Upgrade note / Обновление

Desktop app and server: install the new app, then `sudo vibechat-server update` (the Studio is served by the server). An older server works with the new app: the app opens Settings through its own proxy. / Приложение и сервер: установите новое приложение, затем `sudo vibechat-server update` (Studio отдаёт сервер). Старый сервер работает с новым приложением: приложение открывает настройки через свой прокси.

Check every asset against this release's `SHA256SUMS`. / Сверьте файлы с `SHA256SUMS` этого релиза.
