## 0.2.14

### Fixed / Исправлено

- **Sites with their own sign-in now work in the preview.** The preview proxy removed every `Cookie` header from requests to the project's dev server, so a site's own session cookie (for example the Go starter's `site_session`) never reached it: sign-in to a cabinet appeared to succeed and then returned to the login page. The proxy now removes only its own two preview cookies (`vibechat_preview`, `vibechat_preview_lax`), which project code must not see, and forwards all others. / **Сайты со своим входом теперь работают в превью.** Прокси превью убирал заголовок `Cookie` из всех запросов к dev-серверу проекта, поэтому собственный cookie сессии сайта (например `site_session` у Go-стартера) до него не доходил: вход в кабинет как будто проходил и тут же возвращал на страницу входа. Теперь прокси убирает только два своих cookie превью (`vibechat_preview`, `vibechat_preview_lax`), которые не должен видеть код проекта, а остальные передаёт.

### Upgrade note / Обновление

Server: `sudo vibechat-server update`. The desktop app is unchanged apart from its version. / Сервер: `sudo vibechat-server update`. Приложение для компьютера не изменилось, кроме номера версии.

Check every asset against this release's `SHA256SUMS`. / Сверьте файлы с `SHA256SUMS` этого релиза.
