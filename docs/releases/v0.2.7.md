## 0.2.7

Import ZIP into an empty project, svelte or react only. / Импорт ZIP в пустой проект, только svelte или react.

### New / Новое

- The Empty starter is empty: runner `none` and an empty first commit. / Шаблон Empty пустой: runner `none` и пустой первый коммит.
- `POST /projects/:id/import.zip` imports a ZIP into an empty project (svelte or react only). The archive is checked for `ui8kit.config.json`, allowlisted dependencies, no lifecycle scripts, and banned paths or symlinks; starter tooling is overlaid without overwriting `src`; then `bun install --ignore-scripts` runs in the jail and the import is committed as `Import ZIP (svelte|react)`. / `POST /projects/:id/import.zip` импортирует ZIP в пустой проект (только svelte или react). Архив проверяется: `ui8kit.config.json`, только разрешённые пакеты, без lifecycle-скриптов, без запрещённых путей и симлинков; инструменты стартера накладываются, не перезаписывая `src`; затем `bun install --ignore-scripts` в изоляции и коммит `Import ZIP (svelte|react)`.
- The Studio Import ZIP file picker uses the Input primitive. / Выбор файла «Импорт ZIP» в Studio использует примитив Input.

### Security / Безопасность

- The isolated jail can reach the agent-bridge port on the shared network, but unauthenticated calls get 401 and the host token file is not visible in the jail (tested). / Из изоляции виден порт agent-bridge в общей сети, но запросы без авторизации получают 401, а файл токена хоста в jail не виден (есть тесты).

To update the server: `sudo vibechat-server update`. Check every asset against this release's `SHA256SUMS` (the server's self-update does the same for the `.deb` before `dpkg -i`).
Обновление сервера: `sudo vibechat-server update`. Сверьте файлы с `SHA256SUMS` этого релиза (самообновление сервера так же проверяет `.deb` перед `dpkg -i`).
