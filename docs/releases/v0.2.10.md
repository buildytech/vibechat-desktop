## 0.2.10

The Go templ preview shows in the Studio frame; syntax highlighting; calmer waits. / Превью Go templ показывается во фрейме Studio; подсветка синтаксиса; спокойное ожидание.

### Fixed / Исправлено

- The preview gateway removes `X-Frame-Options` and the CSP `frame-ancestors` directive from the dev server's answers. The Go templ starter (and a templ ZIP such as it-shop) sends `X-Frame-Options: DENY` and `frame-ancestors 'none'`, so after the "Building the Go site…" page the Studio iframe showed "refused to connect" (`<id>.preview.localhost` отказано в подключении) although the site was up and answered 200. Vite previews never set these headers. The gateway still serves only a request with a grant, its session cookie or a same-origin mark. / Шлюз превью убирает `X-Frame-Options` и директиву CSP `frame-ancestors` из ответов dev-сервера. Стартер Go templ (и templ ZIP, например it-shop) отдаёт `X-Frame-Options: DENY` и `frame-ancestors 'none'`, поэтому после страницы «Building the Go site…» iframe Studio показывал «отказано в подключении», хотя сайт работал и отвечал 200. У Vite-превью этих заголовков нет. Шлюз по-прежнему пропускает только запрос с грантом, cookie сессии или отметкой same-origin.

### Added / Добавлено

- Editor syntax highlighting for `go`, `svelte`, `templ`, `mdc`, `sh`, `env` and `conf` (Studio da36667). / Подсветка синтаксиса в редакторе для `go`, `svelte`, `templ`, `mdc`, `sh`, `env` и `conf` (Studio da36667).
- ZIP import shows an indeterminate wait with the current step and elapsed time; the Go build placeholder page (still 503 until the first build ends) has the same calm animation, no made-up percentages, respects `prefers-reduced-motion`. / Импорт ZIP показывает неопределённое ожидание с текущим шагом и временем; страница-заглушка сборки Go (503 до конца первой сборки) получила такую же спокойную анимацию, без выдуманных процентов, с учётом `prefers-reduced-motion`.

### Upgrade note / Обновление

Server only: `sudo vibechat-server update`, then press Play again (the running preview keeps the old proxy until it restarts). / Только сервер: `sudo vibechat-server update`, затем снова нажмите Play (запущенное превью держит старый прокси до перезапуска).

Check every asset against this release's `SHA256SUMS`. / Сверьте файлы с `SHA256SUMS` этого релиза.
