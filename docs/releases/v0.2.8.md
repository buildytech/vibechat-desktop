## 0.2.8

Go templ projects: a new Go template and Import ZIP of BuildY Chat's templ export, built and previewed on the server. / Проекты Go templ: новый Go-шаблон и импорт ZIP templ-экспорта BuildY Chat со сборкой и превью на сервере.

### New / Новое

- Template **Go templ starter** (`templ`): fastygo/starter at the commit BuildY Chat's templ export pins (`cf9d7db`), Go 1.27 · templ · PocketBase · Tailwind 4 · UI8Kit. It is a layer over Empty: the server downloads the pinned tree once and checks every file by SHA-256 before use. / Шаблон **Go templ starter** (`templ`): fastygo/starter на том же коммите, что и templ-экспорт BuildY Chat (`cf9d7db`). Это слой поверх Empty: сервер один раз скачивает дерево и сверяет каждый файл по SHA-256.
- Import ZIP accepts Go templ projects through the same `POST /projects/:id/import.zip` and the same shared checks (empty project, size limits, path safety, symlinks, `.env`, now also executable binaries). The framework comes from `manifest.json` (`buildy.pack.v1`), else from `ui8kit.config.json` (svelte/react, as in 0.2.7) or `go.mod`. / Импорт ZIP принимает Go templ через тот же endpoint и те же общие проверки (плюс запрет исполняемых бинарников). Фреймворк берётся из `manifest.json` (`buildy.pack.v1`), иначе из `ui8kit.config.json` (как в 0.2.7) или `go.mod`.
- Go checks on import: `go`/`toolchain` not above Go 1.27.4, `tool` only templ, `replace` only to a folder inside the project, modules only from the starter's `go.sum`, `go.sum` required, no cgo, `//go:generate` only `go run ./gen` or `go tool templ generate`, no `vendor/`, `go.work`, `bin/`, `pb_data/`, C/assembly/object files. Missing tooling (`AGENTS.md`, `Makefile`, `.cursor/`, `scripts/`) comes from the template; then `go mod download` and `go build` in the jail. / Go-проверки при импорте: версия не выше 1.27.4, `tool` только templ, `replace` только внутрь проекта, модули только из `go.sum` стартера, без cgo, `//go:generate` только известные генераторы, без `vendor/`, `go.work`, бинарников. Недостающие инструменты берутся из шаблона; затем `go mod download` и `go build` в изоляции.
- Live preview of Go projects: `vibechat-server go-dev` (templ generate + go build, rebuild on save, a "Building…" page while building, the build log on failure, ready on `/healthz`) behind the same preview proxy. One Go build at a time on the server. / Превью Go-проектов: `vibechat-server go-dev` (templ generate + go build, пересборка при сохранении, страница «Building…» во время сборки, лог при ошибке, готовность по `/healthz`) через тот же прокси превью. На сервере одна Go-сборка за раз.
- Import answers report each file's layer (`layers`: core, data, code). / Ответ импорта показывает слои файлов (`layers`: core, data, code).
- Import code is a registry of framework adapters (svelte, react, templ; php-flight planned): [ADR 0001](https://github.com/buildytech/vibechat-desktop/blob/main/docs/adr/0001-import-adapters-and-go-runner.md). / Импорт устроен как реестр адаптеров (svelte, react, templ; php-flight в плане): ADR 0001.

### Server / Сервер

- Go 1.27.4 (pinned by SHA-256) in `/opt/vibechat/go`: the setup wizard installs it; the package's postinstall runs `vibechat-server ensure-go`; `vibechat-server doctor` checks it. / Go 1.27.4 (закреплён по SHA-256) в `/opt/vibechat/go`: ставит мастер настройки, postinstall пакета запускает `vibechat-server ensure-go`, проверяет `vibechat-server doctor`.
- Go runs isolated like Bun: shared module and build caches, `GOFLAGS=-mod=readonly`, `GOTOOLCHAIN=local`, `CGO_ENABLED=0`. / Go работает в изоляции, как Bun: общие кэши, `-mod=readonly`, `GOTOOLCHAIN=local`, без cgo.
- Egress allowlist adds `proxy.golang.org`, `sum.golang.org`, `dl.google.com`. / В allowlist добавлены `proxy.golang.org`, `sum.golang.org`, `dl.google.com`.

### Upgrade note / Обновление

An existing server has the old egress allowlist, so `ensure-go` during the update cannot reach `dl.google.com`; the server keeps running and doctor shows `go` missing. Re-run the setup wizard (the egress and server steps) from the app to add the Go domains and install Go, or add the three names to `/etc/vibechat/egress.domains` on the host and run `sudo vibechat-server ensure-go` in the container. / На уже установленном сервере старый allowlist, поэтому `ensure-go` при обновлении не дойдёт до `dl.google.com`; сервер продолжит работать, doctor покажет, что `go` нет. Перезапустите мастер настройки (шаги egress и server) или добавьте три домена в `/etc/vibechat/egress.domains` на хосте и выполните `sudo vibechat-server ensure-go` в контейнере.

To update the server: `sudo vibechat-server update`. Check every asset against this release's `SHA256SUMS` (the server's self-update does the same for the `.deb` before `dpkg -i`).
Обновление сервера: `sudo vibechat-server update`. Сверьте файлы с `SHA256SUMS` этого релиза (самообновление сервера так же проверяет `.deb` перед `dpkg -i`).
