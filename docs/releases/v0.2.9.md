## 0.2.9

Go templ projects on a server behind the egress allowlist: module downloads work. / Проекты Go templ на сервере с egress-allowlist: модули скачиваются.

### Fixed / Исправлено

- Egress allowlist adds `storage.googleapis.com`. The Go module proxy (`proxy.golang.org`) answers a module download with a redirect there, so on a server with the 0.2.8 allowlist `go mod download` of a Go templ project failed (the first Play of **Go templ starter** or a templ ZIP import ended with "installing dependencies failed"). / В allowlist добавлен `storage.googleapis.com`. Прокси модулей Go (`proxy.golang.org`) отдаёт скачивание модуля редиректом туда, поэтому на сервере с allowlist 0.2.8 `go mod download` Go templ проекта падал (первый Play **Go templ starter** или импорт templ ZIP заканчивался «installing dependencies failed»).

### Upgrade note / Обновление

The server update does not change the host's allowlist. Re-run the setup wizard's egress step from the app, or add `storage.googleapis.com` to `/etc/vibechat/egress.domains` on the host and run `sudo /usr/local/sbin/vibechat-egress`. Then press Play again: the project installs its modules. / Обновление сервера не меняет allowlist хоста. Перезапустите шаг egress мастера настройки или добавьте `storage.googleapis.com` в `/etc/vibechat/egress.domains` на хосте и выполните `sudo /usr/local/sbin/vibechat-egress`. Затем снова нажмите Play: проект докачает модули.

To update the server: `sudo vibechat-server update`. Check every asset against this release's `SHA256SUMS` (the server's self-update does the same for the `.deb` before `dpkg -i`).
Обновление сервера: `sudo vibechat-server update`. Сверьте файлы с `SHA256SUMS` этого релиза (самообновление сервера так же проверяет `.deb` перед `dpkg -i`).
